# Как залить сайт на бесплатный хостинг (Render.com)

Время: ~10–15 минут. Ничего программировать не нужно — только загрузить папку и нажать «Deploy».
Git на компьютере не нужен: всё делается через сайт GitHub в браузере.

Итог: получите ссылку вида `https://friseur-ulrich.onrender.com`, которую можно отправить кому угодно.
Админка будет на `https://friseur-ulrich.onrender.com/admin`.

---

## Шаг 0. Что НЕ надо загружать

Файл `.gitignore` уже настроен, но если грузите вручную через drag-and-drop — **не берите** папку:

- `node_modules/`  (тяжёлая, ставится сама на хостинге)
- `.qa/`           (тесты, не нужны)
- `data/`          (там ваши локальные тестовые заявки; на хостинге создастся своя)

Берите: `server.js`, `package.json`, `package-lock.json`, `index.html`, `admin.html`,
`assets/`, `lib/`, `render.yaml`, `Dockerfile`, `.dockerignore`, `.gitignore`, `README.md`.

---

## Шаг 1. Аккаунт GitHub + репозиторий (5 мин)

1. Откройте https://github.com/signup — создайте аккаунт (или войдите, если есть).
2. На https://github.com/new создайте **новый репозиторий**:
   - Repository name: `friseur-ulrich`
   - Public — ок (код не секретный; пароль админки хранится не в коде, а в настройках Render).
   - **Не** ставьте галочки Add README / .gitignore / license.
   - Нажмите **Create repository**.
3. На открывшейся странице нажмите **uploading an existing file**
   (ссылка «uploading an existing file» в блоке «…or upload an existing file»).
4. Перетащите файлы из шага 0. Внимание: содержимое `assets/` и `lib/` нужно перетащить
   **с сохранением папок** — проще всего перетащить сами папки `assets` и `lib` целиком,
   а рядом — отдельные файлы `server.js`, `package.json` и т.д.
5. Внизу нажмите **Commit changes**. Готово, код на GitHub.

---

## Шаг 2. Render.com — деплой в один клик (5 мин)

1. Откройте https://dashboard.render.com/register и зарегистрируйтесь **через GitHub**
   (кнопка «Sign up with GitHub» → Authorize). Так Render сразу увидит ваш репозиторий.
2. В левом меню: **New** → **Blueprint**.
3. Выберите репозиторий `friseur-ulrich` → **Connect**.
4. Render прочитает `render.yaml` и покажет сервис `friseur-ulrich` (plan: **free**, region: Frankfurt).
5. Впишите секреты (они спросятся один раз):

   | Переменная     | Что писать                                              |
   |----------------|---------------------------------------------------------|
   | `ADMIN_USER`   | логин для входа в админку, например `admin`             |
   | `ADMIN_PASS`   | **свой пароль**, не оставляйте `admin123`               |
   | `SMTP_*`, `MAIL_TO` | оставьте пустыми — почта выключится, заявки всё равно сохранятся в админке. Захотите письма — см. Шаг 5 |

6. Нажмите **Apply** / **Create Services** и подождите 2–4 минуты, пока статус не станет
   зелёным **Live**.

Ссылка появится сверху на странице сервиса: `https://friseur-ulrich-xxxx.onrender.com`.

---

## Шаг 3. Проверка (1 мин)

Подставьте свой адрес:

- `https://ВАШ-АДРЕС/healthz` → должно вернуть `{"ok":true}`  ← сайт жив
- `https://ВАШ-АДРЕС/` → главная страница
- `https://ВАШ-АДРЕС/admin` → вход в админку под `ADMIN_USER` / `ADMIN_PASS`
- на главной заполните тестовую запись → она появится в админке во вкладке «Записи»

Откройте сайт с телефона — версия для мобильных подстраивается сама.

---

## Шаг 4. Что важно знать про бесплатный тариф Render

- Сайт **засыпает** после ~15 минут без посетителей. Первый заход после сна грузится 30–60 сек,
  дальше быстро. Для демонстрации клиенту это нормально.
- **Заявки и отзывы хранятся в файлах** на сервере. При каждом редеплое (новый коммит) или
  засыпании-перезапуске Render может их **обнулить**. Для теста это ок.
- Если нужно, чтобы данные жили постоянно — либо платный план + диск (Render Disk),
  либо проще: настройте почту (Шаг 5), тогда каждая заявка дублируется письмом и не теряется.
- Бесплатный план иногда просит подтвердить аккаунт картой (списание не происходит).
  Если карты нет — смотрите альтернативы ниже.

## Шаг 5. Почта (по желанию, заявки на e-mail)

Нужен почтовый ящик, умеющий SMTP. Проще всего — Gmail с «паролем приложения»:

1. https://myaccount.google.com/security → включить 2FA → App passwords → создать пароль для «Mail».
2. В Render: сервис → **Environment** → добавьте:

   ```
   SMTP_HOST = smtp.gmail.com
   SMTP_PORT = 465
   SMTP_USER = ваш-ящик@gmail.com
   SMTP_PASS = 16-символьный пароль приложения
   MAIL_TO   = куда присылать заявки (можно тот же ящик)
   ```

3. Save → сервис перезапустится сам. Проверьте: отправьте запись с сайта — должно прийти письмо.
   Если SMTP не настроен, форма работает как раньше, а в ответе API приходит `"emailSent": false`.

## Альтернативы, если Render не подходит

- **Koyeb** (https://koyeb.com) — тоже бесплатный план, деплой из GitHub, нужен `Dockerfile`
  (он уже есть в проекте): New App → GitHub → Dockerfile → 1 instance (nano) → Deploy.
- **Fly.io** — бесплатный лимит, деплой через `fly launch` (нужен CLI).
- **VPS/локально** — `npm install` и `npm start`, сайт на http://localhost:8099.

Справка по переменным окружения и структуре проекта — в `README.md`.

## Самый быстрый путь (2 минуты)

На рабочем столе лежит архив **`friseur-ulrich-deploy.zip`** — в нём только нужные файлы,
`node_modules`, тесты и тестовые заявки уже вырезаны.

1. Распакуйте архив в отдельную папку.
2. https://github.com/new → имя `friseur-ulrich` → Create repository.
3. На странице репозитория: **Add file → Upload files** → перетащите всё содержимое папки → **Commit changes**.
4. https://dashboard.render.com/register → «Sign up with GitHub».
5. **New → Blueprint** → выберите репозиторий → вписать `ADMIN_USER` и `ADMIN_PASS` → **Apply**.
6. Через 2–4 минуты откройте `https://ВАШ-АДРЕС/healthz` — если там `{"ok":true}`, сайт в сети.
